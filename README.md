# 工训赛物料搬运小车

基于 STM32F103RC 的全向移动物料搬运机器人，用于中国大学生工程实践与创新能力大赛（工程训练赛）物料搬运赛项。

## 项目概述

本项目实现了一台能够自主导航、识别彩色物块、并通过机械爪完成抓取与放置的物料搬运小车。小车采用麦克纳姆轮实现全向移动，搭载 MPU6050 陀螺仪进行姿态闭环控制，通过串口触摸屏实现人机交互，并与树莓派协作完成上层视觉任务调度。

## 硬件配置

| 部件 | 型号/参数 |
|------|-----------|
| 主控芯片 | STM32F103RCT6（Cortex-M3, 256KB Flash, 48KB RAM） |
| IMU 传感器 | MPU6050（六轴陀螺仪+加速度计） |
| 电机驱动 | 直流电机 ×4（麦克纳姆轮）+ 编码器 |
| 步进电机 | 丝杆升降机构 |
| 舵机 | 机械爪 + 云台 |
| 显示屏 | 0.96 寸 OLED（调试）+ TJC4827T143 串口屏（用户交互） |
| 通信接口 | UART4（树莓派）、UART5（串口屏） |

## 核心功能

- **全向移动** — 基于麦克纳姆轮的平移、直行、旋转运动，支持前进/后退/横移/自转等多种运动模式
- **PID 闭环控制** — 速度环 + 角度环（偏航角）+ 位置环的多级 PID 控制，保障运动精度
- **物料识别** — 通过二维码/颜色传感器识别红、绿、蓝三种颜色的物块
- **自动抓取与放置** — 机械爪配合步进电机升降，实现对物块的精准抓取和分类放置
- **姿态感知** — MPU6050 六轴融合 + 卡尔曼滤波，实时获取小车姿态角度
- **人机交互** — 串口触摸屏显示任务状态、物块信息；OLED 用于实时调试
- **多机通信** — 与树莓派通过串口协议协同工作

## 运动模式

| 模式 | 说明 |
|------|------|
| `FOR_MODE` | 前进 |
| `BACK_MODE` | 后退 |
| `TRANS_MODE` | 横移 |
| `TRANS_LEFT_MODE` | 左平移 |
| `TRANS_RIGHT_MODE` | 右平移 |
| `REVOLVE_MODE` | 原地旋转 |
| `REVOLVE_MODE_90` | 左转 90° |
| `REVOLVE_MODE_0` | 右转 / 回正 |
| `REVOLVE_MODE_180` | 180° 翻转 |
| `LOCATION_MODE` | 定点定位 |
| `LOCATION_PLACE_MODE` | 定点放置 |

## 控制流程

```
初始化 → 等待二维码识别 → 接收树莓派指令 → 物料抓取
   ↓                            ↓
姿态闭环控制 ← PID 多级调节 ← 运动模式切换
   ↓
物料放置 → 下一个任务循环
```

主循环运行在 TIM6 定时器中断中（5 分频），按顺序执行：
1. MPU6050 姿态数据采集
2. 编码器速度计算
3. 运动模式控制
4. PID 控制输出

## 开发环境

- **IDE**: Keil MDK / VSCode + EIDE 插件
- **编译器**: ARM Compiler 5 (AC5)
- **目标芯片**: STM32F103RC（高密度型号 `STM32F10X_HD`）
- **标准库**: STM32F10x Standard Peripheral Library
- **调试器**: ST-Link / CMSIS-DAP (OpenOCD)
- **机械设计**: Autodesk Fusion 360
- **电路设计**: 立创EDA

## 编译与烧录

1. 打开 VSCode，确保已安装 EIDE 插件
2. 打开 `Electronic control/` 目录
3. 选择目标 `Target 1`，点击 Build 编译
4. 连接 ST-Link 或 CMSIS-DAP 调试器
5. 点击 Upload 烧录程序

或使用 Keil MDK 直接打开 `Electronic control/Project.uvprojx`。
